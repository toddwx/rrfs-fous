What should I know about this forecast?

This is an experimental estimate made from RRFS forecast data. It is not an official NWS bulletin. Some fields are approximate, especially humidity and vertical motion. The familiar layout is kept so you can scan it quickly.

The NAM comparison uses NAM model data and a matching official NAM FOUS bulletin from the same forecast run. Temperature layers and six-hour precipitation are being checked first; other fields remain in the research record.
